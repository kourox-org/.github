# KouroX | کوروکس

راهنمای فارسی امنیت ارزهای دیجیتال، محدودیت صرافی‌ها، احراز هویت و مشکلات تراکنش‌ها برای کاربران ایرانی.

🌐 [وب‌سایت کوروکس](https://kourox.org/)

## About KouroX

KouroX is a Persian-language cryptocurrency education project covering wallet security, exchange access policies, KYC requirements and transaction troubleshooting for Iranian users.

## موضوعات ما

- امنیت کیف پول و پیشگیری از فیشینگ
- محدودیت‌ها و الزامات احراز هویت صرافی‌ها
- شبکه‌های انتقال رمزارز و مشکلات تراکنش‌ها
- آشنایی با ریسک‌های استفاده از خدمات رمزارزی

مطالب کوروکس جنبه آموزشی دارند و توصیه شخصی سرمایه‌گذاری نیستند.
